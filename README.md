# BallotBridge (Round 1 prototype)

Start with `SETUP.md`, then copy the two code files into your Apps Script project.

| File | What it is | Where it goes |
|---|---|---|
| `SETUP.md` | Setup steps, pre-session checklist, known limits | Read first |
| `spec.md` | Core interaction, roles, screens, rules, data | Reference |
| `Code.gs` | Backend (Google Apps Script) | Apps Script file `Code.gs` |
| `Index.html` | Single-page UI | Apps Script HTML file named `Index` |

`archive-modular-v1/` holds the earlier modular build. It doesn't work for multi-user testing and isn't part of the prototype.
